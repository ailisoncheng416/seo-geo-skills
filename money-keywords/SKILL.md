# money-keywords — 找能成交的关键词模式

> 思路参考：Nicholas Dulait 的 X 长文（2026）里的同名 skill。本文件是按该思路自行改写的版本，不是原文。
> 数据源：原文依赖 ChatSEO MCP（`https://api.chatseo.app/mcp`）。未接入时改用 Search Console 导出 + `keyword-researcher`（Ahrefs）。

## 原则

- 只要"已经准备掏钱"的搜索：服务 + 城市、产品类目、「X 替代」「X vs Y」等。
- 判断意图不靠工具，看实际排在前面的是什么页面：落地页／服务页／类目页／产品页 = 商业意图；博客和定义框 = 信息意图，先跳过。
- 找的是「模式」不是单个词：一个模式 = 几十个页面。
- 搜索量小不是淘汰理由，打不过才是：按本站当前权重筛掉赢不了的 SERP。

## 步骤

1. 确定站点：从数据源里列出站点，选中本项目对应的那个。
2. 向数据源要一份「按关键词模式分组、只保留商业意图、按本站权重下的可行性排序」的机会清单。
3. 等结果完整返回后再往下做，不要拿半截结果分析。
4. 逐个模式复核：只保留当前前 3 名是落地页／服务页／类目页／产品页的关键词；前排被博客占满的整组丢掉。
5. 写出 `keywords.md`，每行包含：模式、关键词、月搜索量、Google 实际排的页面类型、本站是否已有对应 URL。
6. 搜索量绝不自己编。数据源没给的，写 `n/a`。

## 输出

`keywords.md`（供 `page-brief`、`geo-queries` 读取）。
